# 我的个人博客

这是一个基于GitHub Pages的个人博客项目。

## 项目结构

```
/
├── index.html            # 首页
├── blog.html             # 博客文章列表页
├── about.html            # 关于我页面
├── contact.html          # 联系方式页面
├── css/
│   └── style.css         # 样式表
├── js/
│   └── script.js         # JavaScript脚本
└── posts/
    └── first-post.html   # 博客文章页面
```

## 自定义指南

### 1. 修改基本信息
- 在各个HTML文件中修改`<title>`标签内容
- 在header部分修改博客名称和简介
- 在footer部分修改版权信息和社交媒体链接

### 2. 添加新的博客文章
1. 在`posts`目录下创建新的HTML文件，可以复制`first-post.html`作为模板
2. 在`blog.html`中添加新文章的链接和简介
3. 如果是精选文章，也在`index.html`的精选文章部分添加

### 3. 修改"关于我"页面
- 在`about.html`中修改个人信息、技能和社交媒体链接

### 4. 修改联系方式
- 在`contact.html`中更新你的联系信息和社交媒体链接

### 5. 自定义样式
- 修改`css/style.css`文件以更改网站的外观和感觉

## 部署

此网站是通过GitHub Pages部署的。将代码推送到GitHub仓库后，它会自动部署到你的GitHub Pages网站。
